Pick the build each micro frontend should run, and publish it. Publishing moves one pointer in the live import map: new page loads get that build at once, and open pages swap to it within a few seconds. Older builds stay on the CDN, so going back is the same action. To ship a release of several micro frontends together, pick a version for all of them and publish all changes in one step.
